# 🛒 Aplicação Web em Vue.js

Este projeto consiste numa **aplicação web desenvolvida em Vue.js**, desenvolvida no âmbito da unidade curricular de **Interface Pessoa Náquina (IPM)** da **Universidade do Algarve**.

## 📌 Descrição
Esta aplicação implementa uma interface web com várias páginas (views), gestão de estado global e navegação entre rotas. Inclui funcionalidades como autenticação de utilizadores, gestão de produtos, carrinho de compras e encomendas.

O projeto foi desenvolvido com **Vue.js**, utilizando **Vue Router** para navegação e **Vuex** para gestão de estado.

## 🛠️ Tecnologias Utilizadas
- ⚡ **Vue.js**
- 🧭 **Vue Router**
- 🗃️ **Vuex (store)**
- 🖼️ HTML5 / CSS3 / JavaScript

## ✨ Funcionalidades
- 👤 Registo e autenticação de utilizadores
- 🛍️ Visualização de produtos e categorias
- 🧺 Carrinho de compras
- 📦 Gestão de encomendas
- 🔐 Login / Logout

## 📂 Estrutura do Projeto
- 🖼️ **Assets**: contém os recursos estáticos da aplicação, como imagens e outros ficheiros utilizados na interface gráfica  
- 🧩 **Components**: inclui componentes reutilizáveis da interface (por exemplo, cabeçalhos, rodapés e outros elementos comuns)  
- 📄 **Views**: reúne as diferentes páginas da aplicação, correspondendo às várias rotas disponíveis  
- 🧭 **Router**: responsável pela definição e gestão das rotas da aplicação, permitindo a navegação entre páginas  
- 🗃️ **Store**: gere o estado global da aplicação através do Vuex, incluindo dados de utilizadores, produtos, carrinho e encomendas  
- **App.vue**: componente raiz da aplicação, responsável por estruturar a interface principal  
- **Main.js**: ponto de entrada da aplicação, onde o Vue é inicializado
